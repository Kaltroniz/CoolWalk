🌿 CoolWalk AWS Serverless Architecture

Microclimate-aware pedestrian routing pipeline & spatial analytics on AWS Open Data

☁ Built for AWS Builder Center "Map It"
1. Open Data Sources
Satellite Thermal
USGS Landsat 8/9
Collection 2 L2 surface temperature (TIRS Band 10) via AWS Registry of Open Data.
Copernicus 10m
Sentinel-2 L2A
Red & NIR spectral bands used to compute high-res NDVI vegetation canopy index.
Spatial Network
OpenStreetMap
35,748 directed walking segments, 12,687 intersections, and 974 civic points.
➔
2. Ingestion & Lakehouse
Python Pipeline
Microclimate Scoring
Samples rasters every 15m (183k points). Fuses thermal heat & NDVI into street heat index.
Amazon S3 + Parquet
Apache Iceberg Tables
coolwalk.segments & places stored in open Parquet with ZSTD compression.
Amazon Athena
Serverless SQL Engine
Generates 150m spatial heat grid (2,092 cells) & 20 civic shade priority corridors.
➔
3. Real-Time Services
AWS Lambda (Python 3.12)
Heat-Aware A* Router
~50ms compute. Minimizes length × (1 + α × heat) with bounded detour cap. Warm-pinged by EventBridge.
Amazon API Gateway
HTTP API v2
Low-latency API proxy with 20 req/s rate-limiting, burst throttling, and CORS protection.
AWS Lambda
Cool-Refuge Finder
Ranks nearest 463 parks, water fountains, and metro stations via coolest walking paths.
➔
4. Mapping & Client
Amazon Location Service
Maps & Places v2
Light base map style, place autocomplete, reverse-geocoding, and standard baseline routes.
AWS Amplify Hosting
Secure HTTPS Web App
Zero-dependency client with MapLibre GL, 48-bin heat strip scrubber, and civic exports.
